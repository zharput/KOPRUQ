save-status-toast Kaydet ve ayar değişikliklerinden sonra sağ/sol üstte geçici bildirim (toast) göster. Sunucu yazması başarılı olunca yeşil "Kaydedildi" toast'u çıksın ve 1-2 sn sonra kaybolsun.
