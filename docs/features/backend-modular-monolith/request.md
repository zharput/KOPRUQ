Backend'i tek Maven modülünden oluşan bir Spring Boot modüler monolith'e dönüştür. Klasör yapısı docs/architecture/backend-reference.md'deki hedef ağaçla aynı olsun: com.kopruq.<domain>/{api,application,domain,model,enums,infra} ve com.kopruq.shared/{config,exception,quantity,validation}. Mevcut 17 Maven modülünü domain paketlerine eşle (bridge, rules, generative, analysis + MIDAS infra adapter'ı, terrain, alignment, landxml, loads, materials, layout vb.; eşlemeyi planlayıcı önersin). İş kurallarını modellerde tut (R5). ModuleBoundaryTest'i referanstaki ArchitectureTests desenine göre paket bazlı mimari testlerle değiştir (R3/R4). CLAUDE.md'deki Build & test komutlarını yeni yapıya göre güncelle. Kapsam dışı: kalıcılık (JPA/PostgreSQL/Compose), yeni REST endpoint, yeni harici bağımlılık, mühendislik değeri değişikliği, frontend. Tüm REST sözleşmeleri ve contract testleri korunsun; taşımalar git mv ile yapılsın; her faz tam build ile doğrulansın. Planı docs/features/backend-modular-monolith/plan.md olarak kaydet; kod değiştirme.
